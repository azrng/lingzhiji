# T63 趣味性第二批立项提案（炼丹坊 / 入定挂起抉择）

> 状态：提案待拍板（2026-11-21）。两个方向均为阶段 0 级新功能，拍板后再展开正式 REQ/DES 文档。

## 方向一 · 炼丹坊（T61 P0-a 完整解）

**解决**：灵石经济断裂——奇遇/高阶草变现后灵石迅速膨胀，消费端只有种子/残卷/珍品架（T62 轻量版已垫底）。

**核心循环**：灵草 → 炼丹炉消耗灵石+灵气炼制丹药 → 服用得修为/心得/临时增益（如「聚气丹：次日灌注 +1 天」「悟道丹：心得 +10」）→ 高阶草终于有「价值倍增」的去处（紫云芝原价 35，炼成丹后价值 60+）。

**设计要点（初稿）**：
- 炉位 1 个，炼制需 N 游戏日（入定可跳）；丹方表 4-6 张按境界解锁
- 丹药不入定额折算（防套利）；收益对照 sim 校准（筑基节奏不加速超过 ~10%）
- 新界面：炼丹坊弹层（丹方列表/炉位状态/炼制进度）——本功能唯一新 UI
- 存档 v10（丹方进度/炉位/丹药库存）

**规模**：大（新资源类型+新界面+新表）。价值：种田消耗端大成，高阶草线闭环，修仙叙事最强的模块。

## 方向二 · 入定挂起抉择（T61 P0-c）

**解决**：入定长跨度零决策旁观（「入定 24 天 | 事件 17 起」全是旁观数字）。

**核心机制**：入定期间触发的特殊奇遇不再自动结算，而是**挂起**为「待处理机缘」（上限 1 个）；出关后弹出抉择卡（二选一，如「神秘修士赠种：A 收下种子 ×2 / B 拒收换灵石 20」），选完消失。选择式奇遇二期提前落地，复用委托三动作交互先例。

**设计要点（初稿）**：
- 只有特殊/传说档挂起（普通档照常自动，别把日常变任务）
- 挂起状态入档（encounterState 扩 pendingChoice），出关后强制弹卡（quota 门控沿用）
- 每个 id 写一对选项（9 特殊+传说条目 ×2 = 18 条文案）；收益设计「A 资源 / B 另类资源」无标准答案
- 存档 v10（与炼丹坊共享窗口）

**规模**：中（新交互管线 + 18 条文案）。价值：把长入定从「旁观」变成「期待出关」。
