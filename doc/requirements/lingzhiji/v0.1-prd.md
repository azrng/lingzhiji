## 1. 背景与定位

**为什么做**：做一个"背单词的长期习惯容器"。用修仙种田的无限阶梯养成匹配背单词的每日节奏——每天登录、接任务堂的背单词任务、用灵气催熟灵草、收获变现、兑换更高级的灵种、修为晋级。

**对比逃荒方向的取舍**：砍掉全家生存数值与死亡系统（平衡最难调、劝退风险最高的部分），保留"定额缴纳"作为温和压力来源。代价是戏剧性变弱，换来的是长线可玩性和一半的工作量。

**核心体验**：每天 5–10 分钟，"接任务 → 背单词 → 灵气灌注 → 看着灵草一天天长大 → 收获换来更高级的种子"的治愈系正反馈循环。

## 2. 核心循环

```
任务堂接任务(背单词10词) ──合格──► 灵气 + 贡献点
        │                            │
        │              灵气灌注(1点=全田生长+1天)
        ▼                            ▼
   贡献点换功法/资格          灵草加速成熟
        │                            │
        ▼                            ▼
   解锁高阶灵种资格          收获灵草 ──► 修为+灵石
                                     │
                    ┌────────────────┤
                    ▼                ▼
            每月缴纳宗门定额      坊市自由出售
            (温和压力源)          ──► 买更高级灵种
                                     │
                                     ▼
                    修为积累 ──► 境界突破 ──► 更多灵田/更高阶资格
```

- **短循环（每天）**：分配 3 点行动力（AP）→ 浇灌/灌注/收菜/接任务
- **中循环（每月 30 天）**：缴纳定额 → 剩余灵草自由出售 → 坊市买高阶种子
- **长循环**：灵草阶数（一阶→三阶，MVP）+ 境界阶梯（练气一层→筑基）

**设计铁律**：灵气只能靠任务堂背单词获得，高阶灵种资格只能靠贡献点与境界——学习没有旁路。

## 3. 开局设定

- **故事**：你通过外门试炼，入青云宗（原创名）成为一名灵植弟子。执事分给你三块下品灵田，交代每月缴纳灵草定额，剩下的收成可自由去坊市处置。
- **初始家当**：灵石 50、一阶种子 ×3（青灵草）、灵田 3 块、境界练气一层、贡献点 0
- **灵田设定**：田有聚灵阵，四季恒温恒湿（修仙设定顺便消灭了季节系统，无冬天/无天气）→ 任何时候都能种植

## 4. 时间系统

| 项 | 规则 |
|---|---|
| 时间 tick | 1 回合 = 1 天 |
| 行动力（AP） | 每天固定 3 点，不结转 |
| 定额周期 | 每 30 天 = 1 个月，月末结算定额（见 §10） |
| 历法 | 「入宗第 X 月 · 第 Y 天」（不搞农历，简单直接） |
| 调试 | `?debug=1` 开调试面板：跳天、加资源（仅验证用） |

## 5. 数值系统

### 5.1 资源

| 资源 | 说明 |
|---|---|
| 灵石 | 通用货币，坊市流通 |
| 贡献点 | 任务堂奖励，兑换功法/资格/赎回灵田 |
| 灵气 | 背单词产出，当日灌注用（可存，上限 5，境界提升+上限） |
| 修为 | 收获灵草获得，突破境界用 |

### 5.2 境界（练气一层 → 筑基）

| 境界 | 突破所需修为 | 解锁 |
|---|---|---|
| 练气一层（开局） | — | 灵田 3 块 |
| 练气二层 | 20 | 灵气上限 6 |
| 练气三层 | 45 | 灵田上限 5 块（可开荒） |
| 练气四层 | 80 | 二阶灵草种植资格 |
| 练气五层 | 125 | 灵气上限 8 |
| 练气六层 | 180 | 贡献兑换坊市 9 折资格 |
| 练气七层 | 245 | 三阶灵草种植资格 |
| 练气八层 | 320 | 灵田上限 7 块 |
| 练气九层 | 410 | — |
| **筑基（MVP 里程碑）** | 520 | 结算画面：本局成绩单 + 可继续游玩 |

修为来源：收获灵草（一阶 +1/株，二阶 +3/株，三阶 +10/株）。

### 5.3 没有死亡

本作无健康/饱腹/死亡系统。失败惩罚全部为软性：定额未缴 → 扣贡献 + 罚灵石；连续两月欠缴 → 暂时收回 1 块灵田（可用 100 贡献赎回）。

## 6. 灵草与种植

### 灵草表（MVP 三阶 6 种，阶梯可扩展至九阶）

| 阶 | 名称 | 种子价 | 生长期 | 收获 | 售价/株 | 修为/株 |
|---|---|---|---|---|---|---|
| 一阶 | 青灵草 | 5 灵石 | 15 天 | 5 株 | 4 | +1 |
| 一阶 | 凝露花 | 12 灵石 | 20 天 | 4 朵 | 9 | +1 |
| 二阶 | 紫云芝 | 40 灵石 | 30 天 | 3 株 | 35 | +3 |
| 二阶 | 赤髓参 | 60 灵石 | 35 天 | 3 株 | 50 | +3 |
| 三阶 | 龙血藤 | 180 灵石 | 50 天 | 2 株 | 210 | +10 |
| 三阶 | 九叶莲 | 260 灵石 | 60 天 | 2 株 | 290 | +10 |

- **种植资格**：二阶需练气四层 +，三阶需练气七层 +（贡献点不能替代资格，只能加速）
- **浇灌**：1 AP 灌全部已种田；每 3 天不浇灌 → 当茬产量减半（无枯死）
- **开荒**：1 块 = 2 AP（境界解锁上限后可用）
- **灵气灌注**：1 点灵气 = 所有田生长 +1 天（背单词加速种地的落点）

## 7. 行动清单（每天 3 AP）

| 行动 | AP | 效果 | 备注 |
|---|---|---|---|
| 灌浇灵田 | 1 | 全部地块免缺水 | |
| 收获 | 1/块 | 获得灵草 + 修为 | |
| 开荒 | 2 | 新增 1 块田（上限随境界） | |
| 任务堂（背单词） | 1 | 测验 → 灵气/贡献/心得（§8） | 每天 1 次 |

## 8. 任务堂（背单词，本作核心）

### 8.1 测验

- 进入需 1 AP，每天限 1 次；任务文案包装成"抄录心法口诀/辨灵识字"类宗门杂务
- **10 个英语单词，词→中文释义 4 选 1**（干扰项运行时从词库随机抽）
- 词库：内置 CET4 高频词约 300 个（JSON：word / 音标 / 释义），文件可整体替换

### 8.2 奖励

| 结果 | 奖励 |
|---|---|
| 合格（≥6/10） | 灵气 +3、贡献 +5、心得 +8 |
| 满分 10/10 | 合格奖励 + 额外心得 +4 |
| 不合格（<6） | 灵气 +1、心得 +2 |

### 8.3 心得等级（功法，长线背词动力，每级 100 心得点）

| 等级 | 增益 |
|---|---|
| Lv2 凝神诀 | 所有灵草生长永久 -1 天 |
| Lv3 聚灵诀 | 收获 +15% |
| Lv4 辨灵术 | 测验合格时灵气 +1 |
| Lv5 春霖诀 | 灌注效果 +1 天（即 1 灵气 = +2 天） |

### 8.4 学习统计

全程记录：累计背词数、正确率、任务次数 → 突破筑基时结算画面展示。

## 9. 坊市（自由买卖）

随时可去，不耗 AP。高阶种子需境界资格。

| 商品 | 类型 | 价格 |
|---|---|---|
| 一阶/二阶/三阶种子 | 买 | 见灵草表 |
| 灵草成品 | 卖 | 见灵草表 |
| 功法残卷（心得直购包 +30） | 买 | 120 灵石（金钱换学习进度，非学习替代） |

## 10. 宗门定额（温和压力源）

- 每 30 天月末结算：缴纳 **一阶灵草 ×15 株**（等价折算：凝露花 1 朵 = 2 株，二阶 1 株 = 12 株，三阶 1 株 = 45 株）
- 按期缴纳：贡献 +10
- 未缴足：贡献 -20、灵石罚 10
- 连续两月欠缴：收回 1 块灵田（100 贡献赎回）；灵田最少保留 1 块
- 定额不随境界增长（MVP 简化；二期可随境界升级）

## 11. 随机事件（每天 30% 概率 1 个，正面 60% / 负面 40%）

| 事件 | 类型 | 效果 |
|---|---|---|
| 灵雨 | 正 | 全田生长 +2 天 |
| 灵蝶授粉 | 正 | 随机一块田当茬产量 +1 |
| 师姐路过指点 | 正 | 修为 +3 |
| 拾得散落灵石 | 正 | 灵石 +8 |
| 灵泉涌出 | 正 | 今日灌注效果翻倍 |
| 长老巡视嘉许 | 正 | 贡献 +5 |
| 虫害 | 负 | 随机一块田当茬产量 -1 |
| 灵雀偷食 | 负 | 仓库随机灵草 -1 |
| 阵法波动 | 负 | 全田生长 -1 天 |
| 坊市行情 | 双 | 今日出售价 +50% 或 -30% |

## 13. UI 概述

- **单屏布局**：
  - 顶部状态栏：入宗第 X 月·第 Y 天、境界、修为进度条、灵石、贡献、灵气
  - 中部：灵田格（3→5→7 块，显示灵草类型与生长进度环）
  - 底部：行动面板（剩余 AP + 行动按钮）+ 当日日志流
  - 弹层：任务堂测验（全屏）、坊市、定额结算（月末弹窗）、事件 toast、筑基结算（全屏）
- **视觉方向**：淡雅仙侠手账风——黛青底色 + 云雾纹理 + 金色点缀；图标先用 emoji / 简单 SVG
- **开始画面**：入宗引子两三句 + 开始修行 / 继续存档
- 实现阶段用 frontend-design 技能产出具体视觉稿

## 14. 技术方案

| 项 | 选型 |
|---|---|
| 构建 | Vite 7 + TypeScript strict |
| UI | React 19 + Tailwind CSS 4 |
| 状态 | Zustand 5 |
| 存档 | localStorage，每天行动结束自动存，带版本号 |
| 逻辑层 | `src/game/` 纯 TS（不 import React），UI 只读状态 + dispatch → 单测与模拟器直接复用 |
| 测试 | vitest：覆盖日结算/定额结算/境界突破/测验判分/事件 |
| 平衡模拟器 | `scripts/balance-sim.ts`：无头跑 500 局策略（认真背词派 / 纯种田派 / 摆烂派），输出：突破筑基平均天数、欠缴率、资源曲线；调参目标：认真背词派 60–90 天筑基且明显快于纯种田派（保证学习价值） |

```
src/
├─ game/            # 纯逻辑：types / constants / engine / events / quiz / save
├─ data/words/      # cet4.json 词库
├─ store/           # useGameStore (Zustand)
├─ components/      # TopBar / FieldGrid / ActionPanel / DayLog / QuizModal / MarketPanel / QuotaModal / EventToast / MilestoneScreen
└─ screens/         # StartScreen / GameScreen
```

## 15. 二期非目标（本版不做）

四阶以上灵草、金丹以上境界、炼丹/炼器、宗门任务链剧情、情缘 NPC、斗法/PVP、排行榜与云存档、移动端深度适配、音效。

## 16. 验收标准

1. `npm run typecheck` 与 `npx vitest run` 全绿
2. 浏览器完整跑通：接任务背词 → 灌注 → 收获 → 缴定额 → 买高阶种子 → 突破筑基 → 结算成绩单；并验证一次欠缴惩罚路径
3. 存档：刷新页面后可从上次进度继续
4. 平衡模拟器：背词派 60–90 天筑基且显著优于纯种田派；摆烂派能活着但基本无法晋级（学习有真实价值）
5. 背单词闭环：测验合格后当帧可见灵气 +3、灌注后田地进度立即 +1 天
