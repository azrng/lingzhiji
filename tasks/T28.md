# T28 收获类音效死路径修复

## 任务范围
- T27 交付时发现的 T26 缺陷：播种/收获/上品/买卖日志均 `kind:'action'`，`pushToasts` 只把 `event/settle/breakthrough` 候选喂给 `playSfxForEntries`，且调用在 toast 早退之后 → `sfx-plant/harvest/premium/gain` 四音效从未播放，与 audio-impl.md §3.4 映射表矛盾
- 2026-11-16 用户拍板修复（「这个修复」）

## 根因与修法
- 根因：T26 挂接音效时复用了 toast 的过滤候选，未核对映射表里的 action 类条目路径
- 修法：`playSfxForEntries(entries)` 与 `fxForEntries(entries)` 同口径——在 toast 过滤**之前**喂全量差量（一行移动+改参数）；映射函数本身按 title/icon 判据返回 null，喂全量不会误触发（浇灌/吐纳等无映射不发声）

## 验证
- 新增 `src/__tests__/useUiStore.test.ts` 3 例（mock audio 模块）：action 类喂全量不产 toast、event 类音效与 toast 同源、混合批一次喂全量
- vitest 122/122（119+3）、tsc、浏览器复验：调试面板加灵气→播种→催熟→收获，`sfx-plant.mp3` 与 `sfx-harvest.mp3` Howl 均创建（原死路径复活），摇摆/飘字/零报错照常
- 未单独实测：sfx-gain（出售/购买）与 sfx-premium（20% RNG）——同一条修复路径，映射有单测覆盖
