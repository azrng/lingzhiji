# T46 素材 WebP 瘦身

## 背景
- GitHub Pages 部署加载慢：`public/assets` 44 个文件共 40MB，其中图片约 35MB
- GH Pages 缓存头固定 `max-age=600` 且不可自定义，浏览器缓存救不了首载，体积是根因
- 2026-11-18 摸底试验（repo 外 `D:\temp\imgopt-test`）：sharp 0.35.5，4 类样张压缩 + image-preview-recognizer 视觉验收全部 pass

## 拍板参数（用户已确认「开始」）
| 类别 | 方案 | 样张数据 |
|---|---|---|
| 角色立绘（1024x1536，显示最高 390px） | 50% 降采样（512x768 lanczos3）+ WebP q85 | 2556KB→119KB (4.7%) |
| 雪碧图 sheet（Sprite 百分比定位，单格 512 显示 52px） | 50% 降采样 + WebP q85 | 2361KB→173KB (7.3%) |
| 纸纹/纹理类 | 原尺寸 WebP q85（摸底 q75 已 pass，提到 q85 买断放大风险） | 1438KB→约 60-90KB |
| 场景 jpg（1536x1024 cover 全屏） | 原尺寸 WebP q80 | 464KB→249KB (53.7%) |

## 执行方式
- 单文件试点：character-senior-sister-v2 先转（webp 与 png 并存），改 characters.ts 引用，起 dev 截图给子智能体验收，用户肉眼确认后再全量
- 全量阶段：批转脚本落 `scripts/`（可复现），按类批量转换 + 全仓引用更新（characters.ts / constants / CSS url() / ui.tsx ICON_IMG 等），确认后删 public 下对应 PNG（原稿 git 历史留底；design/concept-art 另有部分原稿）
- 音频降码率（BGM 2.5MB→约 1.2MB）不在本任务，另行任务
- fx-*（雾/萤火/光晕）与 breakthrough-aura 特效类：全量时按实际显示尺寸单独定参，不一刀切

## 风险与注意
- WebP 兼容性：2026 年全主流浏览器支持（Safari 14+），不需要 <picture> 回退
- sheet 降采样必须保持网格整除（1536x1024→768x512，3x2 格每格 256）
- 引用全是 assetUrl() 运行时字符串，Vite 不参与处理——引用更新必须 grep 全覆盖，防止漏改 404
