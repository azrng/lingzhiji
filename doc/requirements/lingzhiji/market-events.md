# 市场事件与行情周期需求

> 状态：approved（2026-11-19 用户「开始」指令确认，三个周期选型按推荐案假设定稿，后续改选仍可回改 §8）。用户提案：坊市之上加市场事件（炼丹大会/宗门采购/灵雨季节/秘境开启），玩家可预判需求提前种植，形成真经营策略；**v1 明确不做实时波动，做固定周期事件池**。

## 1. 背景与目标

现坊市卖价恒定（唯一波动是「坊市行情」随机事件：明日全局 ×1.5/×0.7，碎且不可预期），经营缺少「看行情做决策」的空间。目标：用**月度市场事件**建立可预判、可计算的行情周期，让「囤货待涨 / 提前种植 / 错峰抛售」成为真实策略。与奇遇（日级惊喜）、变异（株级惊喜）互补，行情是**月级规划层**。

参考要点（离线综合，2026-11-27 联网配额恢复后可补研）：星露谷证明「日历驱动种植决策」适合种田调性；动森大头菜证明「行情结构可学习」才让囤货成为玩法；一方灵田证明「需求锚定消耗方（丹方/宗门）」比抽象价格更有叙事。共性：可预期 + 可计算 + 有限窗口。

## 2. 范围

### 包含

1. **月度市场事件池**（v1 五条）：月初抽 1 个持续整月，与灵潮同日双联公告
2. **月中预告**：当月 15 日预告下月事件（预告=必然，沿奇遇「预告必兑现」哲学）——长生长期草的提前种植策略成立
3. **按草定向价格系数**：需求↑（×1.6~1.8）或供应↑（×0.75），持续期内坊市卖价按草查表
4. **归置旧机制**：移除「坊市行情」随机事件与 `marketMult` 全局系数；TOMORROW_HINTS 两条行情氛围文案移除，预告统一走 15 日真话通道
5. 存档迁移（与奇遇/图鉴共享版本升级窗口）

### 不包含（后续批次）

- 实时/逐日波动市场、走势图 UI、期货/预售订单
- 买入端（种子价）随行情波动——v1 只动卖出价，防早期玩家被种子涨价卡死
- 市场事件与灵潮主题的强绑定（v1 独立抽取，主题咬合二期观察）
- 旬制/固定日历轮换（备选形态，见 §8）

## 3. 用户与页面

- 用户：单人本地玩家
- 页面：**无新页面**。坊市弹层顶部新增行情条（事件名+受影响灵草+系数）；月初/15 日公告走逐日日志

## 4. 核心业务规则

### 4.1 周期与预告

| 时点 | 发生什么 |
|---|---|
| 第 1 月 | 无市场事件（引导期）；15 日照常预告第 2 月事件 |
| 每月 1 日 | 上月预告的下月事件生效为当月事件；与灵潮、委托刷新同点双联公告 |
| 每月 15 日 | 掷定并预告下月事件（存档留痕，预告=必然） |
| 无事件月 | 池允许「无事件」结果？v1 不设：每月必有事件（含淡季负向条目） |

- 同一事件**不连续两月**出现（lastEventId 排除）
- 15 日预告后、月初生效前跨入月末定额：不受影响，事件按自然月切换

### 4.2 事件池（v1 五条，系数为初版建议值）

| 事件 | 叙事 | 影响 |
|---|---|---|
| 炼丹大会 | 各家丹坊抢购主药 | 凝露花 卖价 ×1.8 |
| 宗门采购 | 宗门例行收购 | 青灵草 卖价 ×1.6 |
| 灵雨季节 | 野外灵草丰收，供应增加 | 当季适播草 卖价 ×0.75 |
| 秘境开启 | 探秘者采购护身灵植 | 当前境界可种最高档草 ×1.8 |
| 坊市淡季 | 行情冷清（负向月） | 全部草 卖价 ×0.85 |

- 定向草解析：低阶草固定点名（凝露花/青灵草，开局即有）；「当季适播草」「最高档草」结算期动态解析（跨境界/扩容存档安全，沿赠种奇遇先例）
- 与 T56 扩容联动：15 草后定向空间更大，事件定义不改结构只换 target

### 4.3 价格口径（边界，防连锁失衡）

| 口径 | 规则 |
|---|---|
| 坊市出售 | 单价 = 表价 × 当月事件系数（该草未命中则 ×1），向下取整最低 1 |
| 委托奖励 | **月初生成时快照锁定**，不受当月行情影响（契约精神） |
| 定额折算 | 仍按表价 ÷4，不受行情影响（防止行情月折算突变扰乱定额节奏） |
| 种子买入 | 不受行情影响（§2 不包含项） |

### 4.4 策略循环（验收的业务目标）

预告可见 → 决策（囤库存待涨 / 提前种植定向草 / 提前接委托锁价 / 购种扩产）→ 月内兑现。**行情策略收益存在但有上限**（sim 验证：响应行情 vs 无视行情的月收益差建议 ≤ +25%，防囤货必胜）。

## 5. 边界场景

| 场景 | 口径 |
|---|---|
| 15 日入定快进跨月 | 预告与生效都在日结算管线内，逐日轨迹自然记录，无特判 |
| 旧档导入 | v7 迁移补空市场状态，当月无事件，下月 15 日起正常 |
| 预告的事件其定向草已被玩家全卖光 | 事件照常生效（行情与个人库存无关） |
| 秘境开启时玩家境界很低 | 最高档草=当前境界内最高（动态解析），永远「跳一跳够得着」 |

## 6. 权限与非功能

- 单机单人本地，权限不适用；全流程 rngState 确定性，同档同序列结果一致
- 行情不得破坏定额与筑基节奏（sim 硬性验收）

## 7. 验收标准

1. 每月 1 日双联公告、15 日预告下月且必兑现；同事件不连续两月
2. 坊市弹层行情条与实际卖价一致；委托奖励与定额折算不受行情影响
3. vitest：事件抽取与去重、15 日预掷入档、价格查表、动态 target 解析、旧 marketMult 事件移除残留清零、v7 迁移全绿
4. sim 500 局：响应行情策略 vs 无视基线——定额达成率与筑基月数不劣化，行情收益差在设定上限内
5. e2e/smoke：行情条展示、公告与预告日志、行情月卖价变化

## 8. 待确认项（用户未逐项回答，按推荐案假设）

1. **周期形态**：假设「月初抽取持续整月」；备选：固定日历轮换（6 月一轮）、旬制（10 天）
2. **预告窗口**：假设「15 日预告下月」；备选：仅月初揭晓（长周期草策略打折）、前 1~2 天短期预告
3. **旧「坊市行情」事件**：假设「移除，单层行情」；备选：保留叠乘（难平衡）
4. 事件池五条内容与系数（×1.6~1.8 / ×0.75 / ×0.85）、收益差上限 +25%——初版建议值，sim 后定稿
5. 排期：与 T55/T56 同为阶段 0 待确认；三者共享存档 v7 窗口与 endDay 改动面，建议同批实施
