# 境界修行设计（修为 / 突破 / 筑基结算）

## 1. 需求追溯

- 关联需求：REQ-LINGZHIJI-001 §5.2（境界表与后续修行规划）、§5.3（无死亡）、§8.4（学习统计）、§16.2（验收）
- 覆盖：修为累计与自动突破、境界解锁重算、修炼吐纳、筑基里程碑结算、突破后继续游玩边界
- 未覆盖：筑基后新境界（PRD §5.2 明确为方向草案，非本版交付）；欠缴收田规则（economy.md）

## 2. 契约引用

无对外契约；`realm` / `cultivation`（累计修为）/ `milestoneShown` 字段见 CON-LINGZHIJI-SAVE-001 草案。境界阈值与解锁表集中于 `src/game/constants.ts`（PRD §5.2 表为事实来源，练气九层 410 → 筑基 520 累计阈值）。

## 3. 技术设计

### 3.1 修为入账与自动突破

- 唯一入口 `gainCultivation(state, amount)`：修为累计只增不减（下限 0 由钳制兜底）
- 入账点：收获灵草（farming.md，每株修为 × 产量）、修炼吐纳（+1）、部分随机事件（师姐指点 +3）
- 入账后按阈值表扫描：跨越阈值即自动突破到对应层，弹突破提示并触发解锁重算；突破不清零修为（表值为累计阈值，全程 520 到筑基）

### 3.2 解锁重算（派生值不入档）

突破后由境界即时派生，存档只存 `realm`，避免双份事实：

| 派生项 | 规则 |
|---|---|
| 灵气上限 | 基础 5，随境界表提升（最高 9）；当前灵气超出新上限时截断 |
| 灵田上限 | 3 → 5（练气三层）→ 7（练气八层）；持有数（含被收田）< 上限才可开荒 |
| 种子折扣 | 练气六层起买种子 9 折（economy.md） |
| 可种灵植集合 | 按各灵植「种植境界」过滤（farming.md 播种校验） |

### 3.3 修炼吐纳（TUNA，1 AP）

- 每游戏日限 1 次（`tunaUsedToday`），修为 +1；完成后当日不可重复
- 不替代任务堂：推进游戏日仍需完成背词（core-loop.md 门控）

### 3.4 筑基里程碑

- 修为达 520 自动突破筑基：置 `milestoneShown` 前先弹全屏结算（一次性，入档防重复）
- 成绩单内容：入宗天数（游戏日）、当前资源、境界路径（各层突破日志摘要）、功法等级、两库学习统计（quiz.md §3.6，标注「学习回顾数据，不代表掌握证明」）、定额缴纳记录摘要
- 关闭结算后**继续现有循环**：可继续种植、背词、缴纳定额；本版无筑基后境界，修为继续累计只作展示，不可突破金丹
- 二期扩展须兼容旧存档（PRD §5.2）：本版存档结构预留 `realm` 枚举值空间，升级路径见 save.md 迁移说明

## 4. 界面原型

突破提示（EventToast，非阻断）：

```text
┌─ ✨ 境界突破 ─────────────────────┐
│ 练气三层！灵田上限提升至 5 块，   │
│ 可种植紫云芝。                   │
│ [知道了]                        │
└──────────────────────────────────┘
```

筑基结算（MilestoneScreen，全屏一次性）：

```text
┌─ 🎉 突破筑基 · 本局成绩单 ─────────────────────────┐
│  入宗 78 天 · 突破筑基                             │
│  修行: 练气一层 → 筑基（修为 520）                 │
│  功法: 春霖诀 Lv5 ｜ 灵田 5 块                     │
│  ── 学习回顾（不代表掌握证明）──                   │
│  四级: 任务 76 次 · 作答 760 题 · 首答正确率 71%   │
│  六级: 任务 12 次 · 作答 120 题 · 错词池 8         │
│  定额: 缴纳 2 月 · 欠缴 1 月（首月免罚不计）       │
│ [继续修行（本版无后续境界）]                      │
└────────────────────────────────────────────────────┘
```

## 5. 交互与异常

| 场景 | 行为 |
|---|---|
| 一次收获跨多个阈值（如事件+收获叠加） | 直接连跳到最终命中层，逐层合并为一条突破日志 |
| 修为增加但未达下一阈值 | 顶栏进度条更新，无弹窗 |
| 筑基后继续获得修为 | 正常累计并展示；不再触发突破 |
| 刷新时正处于筑基结算屏 | `milestoneShown=false` 入档前已持久化中间态，恢复后重新展示 |

## 6. 验证方式

- vitest：累计不清零、跨阈值自动突破与连跳、派生上限变化（灵气超上限截断、田上限放开开荒）、吐纳每日一次、筑基一次性标记
- smoke test：PRD §16.2 浏览器完整路径的境界段（功法双消耗进阶 → 突破筑基 → 成绩单）
