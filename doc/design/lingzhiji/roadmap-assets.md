- M2 学习强化降级为「线路增强」，可缩水或后移；M3 氛围对种田体验是核心
- **调参遗留**：balance-sim 现实日三档（500 局）：daily1 筑基 69 现实日（P90 70，落在 60–90 目标）、daily2 42 / daily3 30——递减钝化但不压制多推进度；若试玩后希望把最优节奏压向每日 1 游戏，可加大递减（修为 ×0.3）或晨露改为仅当日首个游戏日全额

## M2–M5 方向要点（立项前另走阶段 0）

- **M2 学习强化**：ts-fsrs@5.4.2（MIT，7KB）替换错词池调度（一次性迁移 next(createEmptyCard(t),t,Again/Good)）；发音 Web Speech API 主 + 有道 dictvoice 兜底；ECDICT(MIT) 构建期补音标；题型注册表 + 义→词反选 / 听音辨词 / 灵种拼写；题卡=灵植图鉴拓片质感（素材 #10）+ 答对金光点飞灵气槽
- **M3 生长动画**：素材 #1–#4；离散阶段帧 + pop 过渡，现有 Sprite 网格裁切组件零改造（col 从作物序号改为 stageIndex）
- **M4 融合试点**：灵雨浇灌（拼写挑战答对=免费灌注）+ 词灵图鉴雏形（筑基后长线地基）
- **M5 场景扩展**：藏经阁（任务堂）/ 坊市集市 / 宗门大殿（定额仪式）/ 洞府（统计与图鉴）四场景，每场景一张内景背景 + 场景切换 + 淡入过渡；纯 UI 层改造不动引擎；素材可与 M3 一次性生成（#5–#9）
- **架构基调**：时间只在 clock/应用层；题型与事件走数据表；内容扩展走存档迁移链

## 调研硬事实（避免重复调研）

- ts-fsrs@5.4.2（MIT、7KB gzip、0 依赖、纯函数）；v6 要求 Node≥24 太新别用
- 发音：Web Speech API 全浏览器离线可用（需用户手势解锁）；有道 dictvoice 灰色但 qwerty-learner 23.8k stars 生产先例；音标用 ECDICT（MIT，76 万词条带 cet4/cet6 tag）构建期补齐；qwerty-learner/Monkeytype 均 GPL-3.0 只借鉴机制不引代码词库
- 音频：howler.js 2.2.4 稳定；BGM 首选 Pixabay（免署名、中国风 2 万+首）、音效 Kenney CC0；**FreePD 已永久关闭**；Suno 商用需付费订阅期下载
- 生长动画：业界共识离散阶段帧 + pop 过渡
- 留存设计参照：Melvor「种田不代劳」、Duolingo streak 低门槛 + 冻结自动生效、Anki「初期失败不惩罚延迟有奖励」
