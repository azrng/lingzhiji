## 生成方式与坑

- 端点 `http://aihubgateway-5718-main.sy/v1/images/generations`，模型 `gpt-image-2.6`，OpenAI 兼容；返回 `data[0].url`（PNG 直链，需 UA 头下载），key 不入仓库、脚本与原图留存于会话临时目录。
- `background:"transparent"` 参数会被 echo 成 auto，但实际出 RGBA 透明；提示词写明「透明背景」即可。
- 生成尺寸仅 1024×1024 / 1536×1024 / 1024×1536 三档；小图标按 1024 生成后 LANCZOS 缩制。
- 软光类素材四角常有 alpha=1~7 残留噪点，肉眼不可见但会挂角点校验，统一按 <8 截 0 后落地。
- 首次烛火图标主体跑偏（生成抱礼盒的卡通熊），提示词补「画面中只有这一支蜡烛」后重打通过——**只校验透明角点不看内容会漏检主体错误，生成后必须视觉抽查**。
- 雾气无缝化：裁中带 40% → numpy wrap-shift 半宽 + 中央权重混合 → resize 2048×256 → alpha 上限 45%。
