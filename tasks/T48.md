# T48 顶栏资源胶囊对齐修复

## 目标

用户试玩反馈顶栏资源区「没对齐」；修复四列资源（灵石/贡献/灵气/心得）的结构不齐与数字跳动，同时保证 1280 宽一行放下。

## 问题（2026-11-18 实拍确诊）

- 灵气列底标签「灵气 / 上限 N」为 11px 长文案，其余三列为 12px 二字标签 → 底行字号与长度参差
- 灵气列内联 10px 进度点把列撑宽 → 四列节奏失衡
- 资源数值未用等宽数字（design-system.yaml type_roles.numeric 明确要求，实现漏了）→ 数值变化时宽度跳动
- 修复中曾把列间距 gap-4→gap-5，1280 视口顶栏挤换行（功法/道心掉第二行）→ 回退并缩小点阵（w-2.5/gap-1 → w-2/gap-0.5）抵消「0/5」增量

## 修复

- TopBar.tsx：灵气列与 Res 同构——上限并入数值「0/5」（上限变化时当前值仍直读，动态上限入 tooltip）、标签统一「灵气」text-xs；数值加 tabular-nums
- ui.tsx：Pips 点阵缩小（唯一使用方即顶栏灵气列）
