# 经济设计（资源 / 坊市 / 宗门定额）

## 1. 需求追溯

- 关联需求：REQ-LINGZHIJI-001 §5（资源与数值钳制）、§9（坊市）、§10（宗门定额）、§16.6（验收）
- 覆盖：资源模型与钳制、坊市买卖与行情、应急领种、月末定额结算交互、欠缴惩罚与收田/赎回
- 未覆盖：收田后的田块状态（farming.md）、贡献消耗于功法（quiz.md）、月内天数推进（core-loop.md）

## 2. 契约引用

无对外契约；`resources` / `inventory` / `seeds` / `month`（欠缴账本）字段见 CON-LINGZHIJI-SAVE-001 草案。商品与折算数值表集中于 `src/game/constants.ts`（PRD §9 §10 为事实来源）。

## 3. 技术设计

### 3.1 资源与全局钳制

- 资源：灵石、贡献点、灵气（受境界上限，溢出丢弃）、心得、修为（progression.md 入口）
- `clampResources` 在 game 层每次状态产出出口统一执行（PRD §5.4）：全部下限 0、惩罚截断、生长与产量 ≥0、定额只按整数株
- 贡献 0 时赎田不可用；贡献不足罚扣按现有值截断

### 3.2 坊市（0 AP，随时可去）

**购买**（种子 ×6 + 功法残卷）：

- 种子价 = 表价；练气六层起自动 9 折，单价**向上取整**（`Math.ceil(p * 0.9)`）；残卷不折
- 灵石不足 → 按钮条件不足态并显示缺口；所有种子开局即可买
- 商品项展示：种植境界、播种灵气、库存、当前可种状态；购买未达境界种子前弹确认「当前境界无法播种，仍要购买？」可取消（PRD §9）

**出售**（灵草成品 ×6）：

- 单价 = 表价 × 行情系数（`pendingTomorrow.marketMult` 1.5 或 0.7），**向下取整且最低 1**；无行情时按表价
- 逐株整数出售；出售价不受六层折扣影响

**应急领种**（免费领 1 枚青灵草种子）：

精确谓词（全部成立才可用，领取后自动失效）：

```text
全田为空 && 仓库无任何灵草 && 无「当前境界可种」的种子
&& 灵石 < 最便宜可种种子的折后价
```

- 「可种」只看境界不看灵气（灵气可通过背词补足，不重复发种）

### 3.3 宗门定额（月末交互结算）

触发：core-loop.md 步骤 5 进入 `phase='quota'`。流程为**玩家驱动的弹窗交互**，日推进在结算完成后继续：

```text
QuotaModal:
  展示: 本月需求（一阶灵草 ×15）· 库存折算合计 · 欠缴后果说明
  选择: 各灵草株数步进器（默认按折算值从低到高自动预填建议方案）
  预览: 已选折算合计 / 剩余需求 · 缴纳后库存 · 首月免罚或缴足 +10 贡献
  [确认缴纳]（折算 ≥15 才可用）   [本月不缴]（首月无此惩罚提示）
```

- 折算率 = ⌊成品售价 ÷ 4⌋ 向下取整（对弟子不利方向）；缴纳只按整数株，超额不找零、余株留仓库
- 白天已收获灵草可计入（结算在当日行动之后）

### 3.4 欠缴惩罚状态机

```text
首月（第 1 月末）: 缴或未缴均不罚、不计欠缴；缴足仍 +10 贡献
第 2 月起:
  缴足            → 贡献 +10，连续欠缴清零
  未缴/不足       → 贡献 −20、灵石 −10（下限截断），连续欠缴 +1，当月差额不累计
  连续欠缴 == 2   → 收回 1 块灵田（优先空田，见 farming.md §3.6），连续欠缴清零；
                    仅剩 1 块时不收田但仍清零
```

- `month.unpaidStreak` 与历史结算摘要入档；定额不随境界增长（MVP 简化，二期可调）

## 4. 界面原型

坊市弹层（MarketPanel，完整布局见 `lingzhiji/ui.md`）：

```text
┌─ 坊市 ────────────────────────────────────────────────┐
│ [买] [卖]   今日行情: 灵草售价 ×1.5 ▲（有行情时显示）  │
│ 买: 商品        价格        库存   状态                 │
│    青灵草种子   5 灵石      2      [购买]              │
│    紫云芝种子   40 → 36 灵石 3     [需练气三层 ⚠]     │
│                          ↑ 九折后取整（练气六层+）      │
│    功法残卷     120 灵石   —      [购买 +30 心得]     │
│ 卖: 青灵草      单价 6 灵石(行情)  持有 5   [卖 1][卖全部]│
│ （仓库空时: 暂无灵草可出售，去收获吧 ← empty 态）       │
└────────────────────────────────────────────────────────┘
```

月末定额弹窗（QuotaModal）：

```text
┌─ 宗门定额 · 第 2 月 ────────────────────────────────┐
│ 本月需缴: 一阶灵草 ×15 株（或按折算缴纳）            │
│ 库存折算合计: 34 株 ✓ 足额                          │
│ 选择: 青灵草 12 ▾   紫云芝 1 ▾ (=8 株)  合计 20 株  │
│ 预览: 缴后库存 青灵草 3 · 紫云芝 0 ｜ 奖励 贡献 +10 │
│ [确认缴纳]        [本月不缴: 贡献 −20 · 灵石 −10]   │
└─────────────────────────────────────────────────────┘
```

- 欠缴触发收田时：全屏 toast + 日志「宗门收回了 1 块灵田（已退还种子），可花 100 贡献赎回」

## 5. 交互与异常

| 场景 | 行为 |
|---|---|
| 灵石不足购买 | 条件不足态显示缺口，不弹错误 |
| 购买未达境界种子 | 先弹确认提示当前无法播种，允许取消 |
| 库存折算不足定额 | 「确认缴纳」不可用，只能选择本月不缴（首月提示免罚） |
| 月末弹窗中关闭页面 | 恢复后回到 `phase='quota'` 重开弹窗，无重复扣减 |
| 贡献被罚至 0 且田被收 | 赎回按钮条件不足态「贡献不足（0/100）」；应急领种兜底可继续种 |
| 行情系数与折扣并存 | 折扣只作用于买种子，行情只作用于卖灵草，互不叠加 |

## 6. 验证方式

- vitest：折算取整方向（⌊售价÷4⌋ 与 9 折 ⌈⌉、行情 ⌊⌋ 最低 1）；首月免罚 / 次月罚扣截断 / 连续两月收田与清零；仅剩 1 块不收田；应急领种谓词真值表（含只持有高境界种子场景）；整数株与不找零
- smoke test：PRD §16.6 购种与经营路径（买紫云芝不能种、达练气三层 2 灵气播种成功扣种子与灵气、应急领种）
