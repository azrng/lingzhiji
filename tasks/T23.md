# T23 随机玩法扩展四项落地

> 对应 TASK.md 行：T23（主任务）、T24（图标素材，待做）。创建：2026-11-15。

## 背景与授权

调研结论（本会话）：可玩性单薄点为事件效果固定、收获无波动、月份无差异、词库 group 全空。用户拍板「1 2 3 4 都可以补充」，其中 1=事件数据化+扩容、2=收获随机化、3=月度灵潮、4=词库近义组；需要图片素材的记入任务文档（即本文件 + T24 行）。

## 设计拍板（阶段 0 依据）

1. **事件数据化**：`EventDef` 增 `effect` 效果描述（判别联合），`engine.applyEvent` 改通用解释器；新增 4 事件均为权重 2，用 emoji `icon` 兜底不动 5×2 素材表：
   - 灵兽来访（正，随机生长中田产量 +2，🦌）
   - 仙人残梦（正，心得 +5，🌙）
   - 灵气涌动（正，灵气 +2 走上限截断，🌊）
   - 灵石失窃（负，灵石 −5，🦝）
   - 权重合计 100→98（正 56 / 负 41 / 行情 1），正面占比 60%→57%。
2. **收获上品**：`farming.harvest` 收获时 20% 概率 +1 株（常数 `HARVEST_PRIME_CHANCE/BONUS`），日志注明；青灵草期望 +4%，九叶莲期望 +10%（方差集中在高阶作物）。
3. **月度灵潮**：6 主题循环（灵雨/灵蝶/虫潮/悟道/灵泉/灾劫），按月乘事件权重（1.5~2 倍或 0.5 减免）；月初日志提示（含初始第 1 天）；纯派生不入档，不违反「无季节天气」设定（叙事为宗门灵潮）。
4. **词库近义组**：新增 `scripts/word-groups.ts`（npm run words:groups），按「释义片段包含关系」直接配对生成 group id（片段长度 ≥2、长度差 ≤3、不做传递合并防巨簇），写回 cet4/cet6 JSON（保持 minified）。
