# 奇遇系统需求（三档机缘）

> 状态：approved（2026-11-19 用户「开始」指令确认，按推荐案假设定稿；后续改选仍可回改 §9。代码实施见 tasks/T55.md）。

## 1. 背景与目标

现有随机事件（PRD §11，30% 日触发）承担日常波动，明日预告（time-decouple §3.6）是纯文案氛围钩子。用户提案：在明日预告与逐日事件日志之上发展「奇遇」——更稀有、更有叙事感、可与预告联动的机缘层，为长线经营提供惊喜节奏。

用户 2026-11-19 已拍板：分**三档**（普通 / 特殊 / 传说·机缘）；v1 全部**自动结算**（无选择交互，选择式二期）；与现有事件撞车的例子（灵雨、灵雀偷食、拾得灵石）归置进现有事件，不重复新做。

## 2. 范围

### 包含

1. 三档奇遇：普通（3 个）、特殊（4 个，预告绑定 + 同类冷却）、传说·机缘（2 个，预告绑定 + 全存档限一次）
2. 明日预告升级：特殊/传说奇遇必有前一日伏笔文案，且**预告必兑现**；普通氛围钩子池保留原样
3. 自动结算：日结算时生效，逐日事件日志按档位区分展示；入定快进期间照常触发并进出关摘要
4. 存档迁移 v6→v7：奇遇队列 / 冷却 / 限次状态

### 不包含（后续批次）

- 选择交互（散修交换真选择、藏宝图多步寻宝、妖兽救治分支）——二期，可复用委托「接/交/弃」交互先例
- 奇遇图鉴收集页、灵潮调制奇遇频率、连朝灵雨（灵雨奇遇版）
- 负向奇遇（用户例子全正向，v1 不做）

## 3. 用户与页面

- 用户：单人本地玩家
- 页面：**无新页面、无新弹层**。表现落在两处既有位置：逐日事件日志条目（icon + 标题区分档位）、明日预告行（伏笔文案）

## 4. 核心业务规则

### 4.1 档位与触发

| 档位 | 概率（每游戏日） | 冷却/限次 | 预告绑定 |
|---|---|---|---|
| 普通奇遇 | 10% | 无 | 无（预告仍走氛围池） |
| 特殊奇遇 | 4% | 同 id 7 游戏日冷却 | 有：前一日必有伏笔，必兑现 |
| 传说·机缘 | 1% | 每 id 全存档仅 1 次 | 有：同上 |

- 奇遇与日常随机事件（30%）相互独立，可同日并存，互不挤占
- 月末（第 30 日日终）不掷奇遇也不出预告，沿现有「定额结算接管过渡」口径
- 档内无可选条目（全冷却 / 限次用尽）时本次无事发生

### 4.2 奇遇清单与效果（数值为初版建议值，sim 验证后定稿）

**普通奇遇**

| 名称 | 用户提案出处 | 效果 |
|---|---|---|
| 灵雀引路 | 灵雀发现一株野生灵草 | 仓库随机灵草 +2 株（当前境界可种范围） |
| 灵石矿脉 | 发现一块灵石矿 | 灵石 +15（对照日常「拾得散落灵石」+8） |
| 散修易货 | 路过的散修请求交换灵草 | 仓库随机灵草 −1，再随机 +1 株（换到高档赚、低档亏；仓库空则无事发生） |

**特殊奇遇**

| 名称 | 用户提案出处 | 效果 |
|---|---|---|
| 神秘修士赠种 | 神秘修士赠送稀有种子 | 当前境界可种最高档灵草种子 ×2 |
| 灵田异变 | 灵田出现变异灵草 | 随机生长中田下茬收获保底出变异株（无生长中田无事发生；效果联动 herb-codex 变异系统，待拍板） |
| 救助幼兽 | 遇见受伤的小妖兽 | 修为 +5、心得 +5 |
| 掘得遗藏 | 发现前任修士留下的藏宝图 | 灵石 +30（v1 直接挖到，多步寻宝二期） |

**传说·机缘**（AI 补案，待拍板）

| 名称 | 效果 |
|---|---|
| 祖师遗府 | 修为 +25、心得 +15 |
| 上古灵泉 | 全田生长 +3 天 |

### 4.3 预告与兑现

- 特殊/传说奇遇触发的前一游戏日，明日预告位出该奇遇的固定伏笔文案（每 id 一条）
- 预告即承诺：有伏笔的奇遇次日必触发，不跳票
- 普通奇遇与无奇遇日的预告维持现有氛围钩子池，不绑定

### 4.4 归置说明（与现有事件的边界）

灵雨、灵雀偷食、拾得散落灵石已是日常随机事件，保留现状；奇遇不收编、不复制。奇遇的辨识标准：稀有概率 + 日志档位标识 + （特殊及以上）预告绑定。

## 5. 关键业务对象

| 对象 | 业务含义 |
|---|---|
| 奇遇档位 | 普通/特殊/传说三级稀有度，决定概率、冷却与预告绑定 |
| 奇遇队列 | 已掷定、等待次日兑现的奇遇（保证预告必兑现） |
| 奇遇冷却 | 同 id 特殊奇遇两次触发的最小间隔（7 游戏日） |
| 限次 | 传说奇遇全存档生命周期仅触发一次 |
| 伏笔文案 | 特殊/传说奇遇的预告位专属文案，与奇遇一一对应 |

## 6. 边界场景

| 场景 | 口径 |
|---|---|
| 仓库为空时散修易货 | 无事发生，不扣不换（沿现有「无有效目标不顺延不替换」惯例） |
| 无生长中田时灵田异变 | 无事发生，冷却仍开始计 |
| 传说两个都用尽 | 该档roll视为无事，不降级 |
| 特殊档全冷却 | 同上 |
| 月末入定提前出关 | 出关日无预告无新队列；已入队奇遇在下次日结算兑现 |
| 入定快进中 | 奇遇照常逐日触发，伏笔与兑现进出关摘要逐日轨迹，叙事连贯 |

## 7. 权限与非功能

- 单机单人本地游戏，权限不适用
- 奇遇由存档 rngState 确定性驱动：同存档同操作序列结果一致
- 全档效果不得破坏定额与筑基节奏（sim 500 局对照验证，硬性验收）

## 8. 验收标准

1. 玩家视角：每个分钟级 session（约 10~30 游戏日）大概率遇到 ≥1 次奇遇；特殊奇遇必有前日预告且次日兑现，无跳票
2. 传说奇遇同存档不重复出现
3. vitest：队列预掷与兑现、冷却、限次、档内池空、无目标无事、月末不掷、入定轨迹、存档 v6→v7 迁移与导入校验全绿
4. sim 500 局：奇遇开启前后定额达成率与筑基节奏（月数）不劣化；奇遇频次分布符合 10/4/1 设定
5. e2e/smoke：日志档位标识与预告伏笔文案正确展示

## 9. 待确认项

1. 概率 10% / 4% / 1% 与冷却 7 天、各项数值——初版建议值，可调
2. 传说档两个条目（祖师遗府 / 上古灵泉）内容与数值——AI 补案
3. 散修易货「随机换随机」方案是否保留（备选：删除该条或改纯正向）
4. 排期：等 T54（闭关纳灵，另一会话在途）落地后进入阶段 1
5. 灵田异变效果联动变异系统（herb-codex §4.2）：原案「当茬产量 ×2」为回退方案，随变异触发模型一并拍板
