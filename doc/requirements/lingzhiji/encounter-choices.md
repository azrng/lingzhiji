# 入定挂起抉择需求（选择式奇遇二期）

## 1. 背景与目标

趣味性走查 P0-c：入定长跨度是零决策旁观（「入定 24 天｜事件 17 起」全是旁观数字）。本需求把**特殊/传说奇遇在入定中触发时挂起为待处理机缘**，出关后二选一结算——把长入定从「跳过键」变成「期待出关」。选择式奇遇二期（encounters.md 既定方向）提前落地。

## 2. 范围

### 包含

1. 入定批量结算中触发的**特殊/传说档**奇遇挂起（普通档照常自动，日常节奏不打断）
2. 出关后弹抉择卡：二选一（各有收益文本），选后结算入账；月末出关时定额结算完成后补弹
3. 每个 id 一对选项文案（特殊 4 + 传说 2 = 6 id ×2 = 12 条），收益设计为「A 资源 / B 另类资源」无标准答案
4. 存档 v10：挂起状态入档（跨现实日持久）

### 不包含

- 手动 END_DAY 的奇遇仍自动结算（不把日常变任务）
- 普通档挂起、多机缘同时挂起（上限 1）
- 选项失败分支（两选项都保证可结算，无「无事发生」态）

## 3. 用户与页面

- 用户：单人本地玩家
- 页面：出关后自动弹出抉择卡（唯一新 UI，模态一层）：奇遇名 + 伏笔回顾 + 两个选项块（标题+收益描述）+ 确认按钮；选择后按正常日志入账

## 4. 核心业务规则

| 规则 | 内容 |
|---|---|
| 挂起条件 | 入定批量结算中 rollEncounter 命中特殊/传说档 → 不结算，存 `pendingChoice` |
| 挂起上限 | 1 个（入定中第二个特殊奇遇照常自动结算） |
| 出关弹卡 | 出关回灵田后自动弹；落在月末时定额结算完成后的首个 day 相弹 |
| 选择结算 | 选中的选项 effect 走共用解释器入账；冷却/限次在选择时置位（沿兑现口径） |
| 未选持久 | 卡可关闭（「暂且搁下」）→ pendingChoice 保留，下次进游戏继续弹（不消失不腐烂） |
| 确定性 | 选项内容固定（每 id 预写），rng 只在入账类效果内部使用 |

## 5. 边界场景

| 场景 | 口径 |
|---|---|
| 入定跨月出关落 quota | 卡延迟到定额结算后首个 day 相 |
| 挂起期间玩家导出/导入存档 | pendingChoice 随档走，导入校验白名单 |
| 两选项效果的目标缺失（如保底变异无生长中田） | 选项文案标注前置；效果结算沿「无事发生」附注惯例，选择仍消耗 |
| 传说档挂起 | seenOnce 仍限一次（选择时留痕） |

## 6. 验收标准

1. 入定中出现特殊/传说奇遇 → 出关必弹卡，选项结算正确入账
2. 普通档与手动 END_DAY 不受影响；挂起上限 1
3. vitest：挂起/出关弹卡前置/选择结算/冷却限次置位/未选持久/月末延迟弹卡/存档 v10 迁移全绿
4. e2e/smoke：抉择卡展示与选择流转

## 7. 待确认项

1. 12 条选项文案与收益数值（初版见设计 §3.3，拍板可调）
2. 挂起上限是否扩到 2（长入定 24 天可能命中 2 个特殊档——当前第二个自动结算的口径是否可接受）
