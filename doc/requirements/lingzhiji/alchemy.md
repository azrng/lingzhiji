# 炼丹坊需求（灵草消耗端与修为倍增线）

## 1. 背景与目标

趣味性走查 P0-a 完整解：灵石经济断裂（消费端只有种子/残卷/珍品架）+ 高阶草收获后除卖出外无去处。炼丹坊把「灵草 + 灵石 + 灵气 → 丹药 → 修为/心得」做成第二条转化线：种田产出有了价值倍增的去处，修仙叙事最契合的模块成型。

## 2. 范围

### 包含

1. 丹方表 5 张（境界 0/2/4/6/8 各一张，材料跨草组合）
2. 炼制：占炉位 1 个，消耗灵草+灵石，N 游戏日后成丹；入定照常推进炉位
3. 成丹即服：领取时直接生效（修为/心得），**丹药不入库存**（不做丹药物品维度，库存/坊市/定额零污染）
4. 炼丹坊弹层（唯一新 UI）：丹方列表（材料/消耗/时长/效果/可炼状态）+ 炉位状态
5. 存档 v10：炉位状态

### 不包含

- 丹药库存/服用时机选择（成丹即服，KISS）
- 炸炉/失败率（达成条件即成功，沿播种哲学）
- 丹药交易、多炉位、丹方图鉴

## 3. 用户与页面

- 用户：单人本地玩家
- 页面：ActionPanel「炼丹」按钮 → 炼丹坊弹层；炉位成丹后按钮带徽记提示

## 4. 核心业务规则

| 规则 | 内容 |
|---|---|
| 开炼条件 | 境界达标 + 材料齐（库存扣草）+ 灵石足 + 灵气足 + 炉位空 |
| 炉位 | 全局 1 个；占用期间不能再开新炉；入定批量照常推进 doneDay |
| 成丹 | doneDay 到达当日的日终置「可领取」；领取时效果生效（修为走 gainCultivation 统一口） |
| 数值锚 | 丹药修为/总投入的效率略高于「卖草买残卷」路径（价值倍增的来源），但 sim 验证筑基节奏提速 ≤10%（硬性验收） |
| 材料扣取 | 开炼时一次性扣除（中途不可撤，炉位占用即成本） |

## 5. 边界场景

| 场景 | 口径 |
|---|---|
| 炼制中跨月/欠缴/收田 | 炉位不受定额影响（丹炉是弟子私产）；收田不收回炉位 |
| 成丹日出关 | 出关摘要提示「丹成可领」；领取动作 phase 门控沿全局口径 |
| 材料中含奇遇入账草 | 照常可用（都是库存） |

## 6. 验收标准

1. 五张丹方全链路：开炼（扣材料）→ 跳天数 → 领取生效 → 炉位释放
2. vitest：开炼校验序/材料灵气灵石扣除/doneDay 推进/领取效果/炉位互斥/存档 v10 迁移全绿
3. sim 500 局：加炼丹策略对照——筑基节奏提速 ≤10%、定额达成率不劣化
4. e2e/smoke：弹层展示与炼制流转

## 7. 待确认项

1. 五张丹方材料/数值（初版见设计 §3.3，sim 后定稿）
2. 丹药效果当前只做修为/心得两类即时收益（不做临时 buff）——是否够
