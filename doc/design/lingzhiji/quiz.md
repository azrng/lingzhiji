# 任务堂背单词设计

## 1. 需求追溯

- 关联需求：REQ-LINGZHIJI-001 §8（任务堂全节）、§12（参数表）、§16.5 / §16.7（验收）
- 覆盖：测验会话状态机、抽题与补题、先学后测、错词池、跨词库记录、奖励、功法升级、学习统计
- 未覆盖：词库数据口径（CON-LINGZHIJI-WLIB-001 + PRD §8.1）、日推进门控（core-loop.md）

## 2. 契约引用

| 契约 | 说明 |
|---|---|
| CON-LINGZHIJI-WLIB-001 | 词库 JSON（`src/data/words/cet4.json` / `cet6.json`）：word / meaning / phonetic（暂空）/ group（可选近义组）；抽题与干扰项的输入 |
| CON-LINGZHIJI-SAVE-001 | `quiz`（会话与每日状态）、`learning`（分库记录与错词队列）、`gongfaLevel` 字段见草案 |

## 3. 技术设计

### 3.1 测验会话状态机

```text
idle ─开始─► learning ─看完本场新词─► testing ─答满 10 题─► result ─确认─► rewarded(当日完成)
                 │                      │                    │
                 └──── 中断（退出/刷新）：session 全量入档，恢复后回到当前相位，不重抽 ────┘
```

- 会话字段：`lib`（生成后锁定）、`words[10]`（含每题来源 new/review）、`phase`、`idx`、`answers[]`（记录首答与正误）
- 每游戏日 1 次奖励：`quizDaily.done` 置位后当日不可再领；进行中固定词库，结束或开始前可切换
- 以首次作答计分；确认结果才发奖并解锁「结束当天」

### 3.2 抽题（`buildSession(state)`）

1. 名额 = 10；复习配额按境界：练气一至三层 3、四至六层 4、七至九层及筑基后 5（新词 = 10 − 复习）
2. 复习候选（当前库内，均按归一化词 `trim().toLowerCase()` 识别同词）：
   - 先取错词池：等待最久（队首）优先
   - 不足再取已见未在错池词：按最近作答时间从早到晚
3. 新词候选：当前库未见词中 PRNG 随机抽取
4. 补足链：复习不足 → 新词补；新词不足 → 尚未选入的已见词补；同场 10 词不重复
   - 补入的已见词仍标记为复习，不提前展示释义，并计入复习统计；因此新词不足时复习数可超过目标配额。
5. 生成前后校验可用性：凑不齐 10 个不同词 → 拒绝 `LIBRARY_INSUFFICIENT`，提示切换词库或修复，保留存档与已答记录

### 3.3 先学后测与作答

- 生成后锁定本场词库与单词；`learning` 相位展示本场**新词**及释义，复习词不提前展示答案
- 每题词→中文释义 4 选 1；答后立即显示正确释义再进下一题
- 作答与推进校验：`QUIZ_LEARNED` 仅在 `learning` 相位有效；`QUIZ_ANSWER` 的选项必须是当前题目的 4 个选项之一，否则拒绝 `INVALID_TARGET` 且不记录作答（防止导入的非法存档或重复提交污染统计）
- 释义清理（词库装载时 `cleanMeaning`）：同一词性下完全重复的释义段只展示一次，不同词性或不同释义均保留；清理同时作用于学习展示与选项生成
- 干扰项：从当前库 PRNG 抽取 3 个，排除本词、同一非空 `group` 词，以及与正确释义存在完全相同释义片段的词；4 个释义须不同。片段重合只识别明确的字面重复，不能覆盖所有近义表达；凑不齐时提示词库问题，保留已有进度。进行中的存档沿用已生成的题目。
- 中断恢复：从当前 `idx` 继续，已答记录保留；未完成可返回经营，但不能结束当天

### 3.4 错词池与跨库记录

- 错词池按库分队列：答错入队尾；重现答对移出；再答错重新排到队尾；超名额时排队重现（不保证次日全部出现）
- 跨库共享：`seenMap`（归一化词 → 见过标记与最近练习顺序）全库共享，另一库见过的词在本库作为复习候选；出题仍用当前库释义
- 切换词库：进行中不可切；切换不增加次数与奖励；两库作答统计与错词池分别保存

### 3.5 奖励与功法

| 结果 | 结算 |
|---|---|
| 合格 ≥6/10 | 灵气 +3（Lv4 再 +1，溢出丢弃）、贡献 +5、心得 +8 |
| 满分 10/10 | 合格奖励 + 心得 +4 |
| 不合格 <6 | 灵气 +1、心得 +2；仍算完成当日任务，错词进复习 |

功法升级（GONGFA_UP，手动逐级）：心得 100/级 + 贡献消耗 Lv3:50 / Lv4:100 / Lv5:150，不足返回 `NO_INSIGHT` / `NO_CONTRIBUTION`；增益常量集中于 constants（Lv2 生长期 −1 并立即重检成熟；Lv3 收获 ×1.15 向上取整；Lv4 合格灵气 +1；Lv5 灌注 +1 天）。

### 3.6 学习统计（§8.4）

分库记录：累计作答次数、该库作答过的不同单词数、该库首次作答正确率、错词重现答对比例、任务次数、错词池规模；重复作答计入次数不重复计入单词数；跨库见词标记只影响抽题不进他库统计。数据用于筑基成绩单展示（progression.md），不作为掌握证明。

## 4. 界面原型

任务堂为全屏弹层（完整布局见 `lingzhiji/ui.md`），四个相位：

```text
┌─ 任务堂 · 辨灵识字 ──────────────────────────────────────────────┐
│ 入口相位                          │ 学习相位（先学后测）           │
│ 词库: (·)四级 ( )六级             │ 今日新词 3 · 复习 7           │
│ 今日比例: 新词7 + 复习3           │ ┌────────────────────────┐   │
│ [开始今日任务]                    │ │ sow  v. 播种            │   │
│                                  │ │ reap v. 收获            │   │
│ 答题相位                          │ └────────────────────────┘   │
│ 第 4/10 题                       │ [已看完，开始测验]             │
│ "harvest" 的释义是？             │                              │
│ A. 收获  B. 播种                 │ 结果相位                      │
│ C. 除草  D. 灌溉                 │ 7/10 合格 ✓                  │
│ （答后高亮正确项并短暂停留）       │ 灵气+3 贡献+5 心得+8          │
│                                  │ 错题: harvest(收获) …        │
│                                  │ [确认结果，领取奖励]          │
└──────────────────────────────────────────────────────────────────┘
```

```text
┌─ 任务堂 · 不可开始 ──────────────────────────────┐   ← error 态（词库问题）
│ ⚠ 当前词库无法组成 10 个不同单词的题目。          │
│ 可切换另一词库继续；进度与错词已保留。            │
│ [切换词库]  [返回]                               │
└──────────────────────────────────────────────────┘
```

- 中断恢复：入口相位显示「继续今日测验（4/10）」替代「开始」
- 答题区保持安静易读（design-system 候选规范），释义字号不小于正文

## 5. 交互与异常

| 场景 | 行为 |
|---|---|
| AP 为 0 | 仍可进入并完成测验（0 AP 行动） |
| 中途退出 / 刷新 | 回到任务堂继续同一场，不重抽、不重复计分 |
| 词库耗尽新词 | 已见词补足 10 题；整库凑不齐则拦截开始并提示 |
| 干扰项歧义 | 不出题，提示词库问题；替换词库前检查可用性，失败保留原库与存档 |
| 非法作答 / 重复进入测验 | 选项不属于本场题目或重复 `QUIZ_LEARNED` 时拒绝 `INVALID_TARGET`，作答记录不变 |
| 灵气将溢出 | 正常发放，超出上限部分丢弃并在结果页注明「灵气溢出 +N」 |
| 满分但 Lv4 未解锁 | 只得基础奖励；Lv4 生效后合格才 +1 灵气 |

## 6. 验证方式

- vitest：境界比例与补题链（首场全新词 / 新词耗尽 / 两库切换）；错词入池-出池-重排队顺序；首答计分；奖励三档与 Lv4、溢出钳制；功法双消耗与不足拒绝；中断恢复等价（序列化→反序列化后继续作答结果一致）；非法作答与重复 `QUIZ_LEARNED` 拒绝；释义清理保留不同词性、去除同词性完全重复段
- smoke test：PRD §16.5/§16.7 全路径（0 AP 完成、未完成不能结束当天、跨库复习候选、切换不加奖励）
