# 灵植图鉴与稀有变异需求

> 状态：approved（2026-11-19 用户「开始」指令确认，三个关键选型按推荐案假设定稿，后续改选仍可回改 §9）。用户提案：多增加不确定性 + 灵植图鉴收集一大堆灵植 + 灵植支持稀有变异。

## 1. 背景与目标

现有灵植仅 6 种，种满两轮后阵容固定，长线经营缺少「攒收集」的牵引。用户方向：把不确定性铺进日常（每次收获都可能出惊喜），并给收集一个可见容器（图鉴）。与奇遇系统（REQ-LINGZHIJI-ENCOUNTER-001）互补：奇遇是「日」级不确定，变异是「株」级不确定。

## 2. 范围

### 包含

1. **草药扩容首批**：6 → 15 种，境界 1~8 每档有新选择（新草只复用现有 5 种特质，新特质二期）
2. **稀有变异**：收获时每株 3%（初版建议）概率出变异株——当株收获量 ×2 且图鉴留痕；「灵田异变」奇遇改为保证触发一次变异（联动条目，随本需求拍板）
3. **灵植图鉴**：修行卡入口的只读弹层——收集度（基础 X/15 + 变异 Y/15）、按境界分组、条目三态（未解锁剪影 / 已解锁详情 / 变异徽记+计数）
4. 存档迁移（与奇遇系统共享版本升级窗口）

### 不包含（后续批次）

- 收集奖励（集齐给灵石/种子/修为）、图鉴联动背词
- 变异株作为独立库存物品 / 变异种子 / 展示柜（v1 变异不进库存经济链路，理由见设计 §3.2）
- 第二批草药扩容（15 → 30+）、新特质、灵潮/物候对新草的专门调制

## 3. 用户与页面

- 用户：单人本地玩家
- 页面：修行卡「图鉴」按钮（「仓库」旁，沿 T51 仓库入口先例）→ 只读弹层；另有收获时变异飘字/提示（复用动效包既有能力，非新界面）

## 4. 核心业务规则

### 4.1 草药扩容（首批 15 种）

- 每境界覆盖：r0×2、r1×1、r2×2、r3×2、r4×2、r5×1、r6×2、r7×1、r8×2
- 新草遵循现有结构（种子价 / 灵气耗 / 生长期 / 株产 / 卖价 / 心得 / 适播季 / 特质），数值为初版建议值，sim 验证后定稿
- 图鉴按境界分组展示全部 15 种；未种过的显示剪影

### 4.2 稀有变异

| 规则 | 内容 |
|---|---|
| 触发 | 收获时逐株独立判定，3% 出变异株（存档 rngState 确定性） |
| 效果 | 当株收获量 ×2，入普通库存（不产生独立物品）；图鉴该草变异徽记 +1 |
| 奇遇联动 | 「灵田异变」奇遇：随机生长中田下一茬收获必出变异（无生长中田则无事） |
| 图鉴口径 | 解锁=获得过该草（收获/奇遇/交换入账均算）；变异徽记=收获过变异株 ≥1 |

### 4.3 图鉴

- 只读、无操作：不播种不购买，纯收集展示
- 条目内容：名称、立绘/剪影、特质、适播季、生长期、境界门槛、卖价参考、已收获计数、变异徽记与计数
- 收集度两行：基础 X/15、变异 Y/15

## 5. 边界场景

| 场景 | 口径 |
|---|---|
| 变异株收获 | 产量 ×2 一次结算，日志/飘字标注「变异」，库存按普通株入账 |
| 仓库空、图鉴无解锁 | 弹层空态：全部剪影 + 收集度 0/15，不报错 |
| 旧档导入 | 图鉴状态可由库存反推初始值（有库存即解锁），迁移不丢收集感 |
| 委托/定额 | 变异产量加成照常计入库存 → 委托交付与定额当量天然受益，无需特判 |

## 6. 权限与非功能

- 单机单人本地，权限不适用；图鉴数据全本地，无加载等待
- 扩容与变异不得破坏定额与筑基节奏（sim 硬性验收）；变异期望增量 ≈ +3% 总产量，可接受

## 7. 验收标准

1. 15 种草药全部可种、可卖、进委托池（若适用），图鉴三态正确流转
2. 同存档同操作序列，变异出现位置一致（确定性）
3. vitest：变异概率与确定性、×2 收获入账、图鉴解锁/徽记口径、旧档迁移全绿
4. sim 500 局：新草价格表 + 变异增量下，定额达成率与筑基月数不劣化
5. e2e/smoke：图鉴弹层展示与收获变异提示

## 8. 待确认项（用户未逐项回答，按推荐案假设）

1. **变异触发模型**：假设「收获随机 3% + 灵田异变奇遇保证」；备选：仅奇遇/道具触发、播种时决定
2. **扩容规模**：假设「首批 +9 到 15 种」；备选：一步到位 30+、不扩容只做现有 6 种变异
3. **图鉴深度**：假设「v1 只读」；备选：带收集奖励、联动背词
4. 概率 3%、变异效果 ×2、9 种新草数值——初版建议值
5. 排期：与奇遇系统同为阶段 0 待确认，代码待 T54 落地后另启任务
