## 实现记录
- `src/fx.ts` 新增：粒子引擎（懒建 canvas z-45 / DPR≤2 / 同屏≤64 / 无粒子停帧）+ `fxForEntry` 纯函数映射 + `setHarvestAnchor`（收获按钮 dispatch 前记锚点，一次性消费 2s 过期）+ 飘字自管 DOM（`fx-float-text` CSS 关键帧，非 motion 组件——触发命令式、样式单一）
- `useUiStore.pushToasts`：`fxForEntries(entries)` 挂在 **toast 过滤之前**（收获/播种 kind:'action' 不产 toast 但需要粒子飘字）；音效行未动
- `EventToast`：AnimatePresence + motion 弹性进出场（spring 260/24，退场 0.2s）；bad=fx-pulse-error 一次性脉冲、gold=fx-glow-gold；useReducedMotion 纯淡入淡出
- `FieldGrid`：mature 田格 plot 精灵套 `.fx-sway`（animationDelay 按 fid 错相）；收获按钮 onClick 先 `setHarvestAnchor(e.currentTarget)` 再 dispatch
- `ui.tsx`：Btn onClick 签名 `() => void` → `(e) => void`（放宽，既有调用零影响）
- `theme.css`：fx-sway / fx-float-up / fx-pulse-error / fx-glow-gold / fx-press（animation 而非 transition，避免与组件 transition-* 覆盖）+ prefers-reduced-motion 全降级
- 设计文档三处按实现事实回改：状态名 ready→mature、飘字「+N 灵石」→「+N 株」（收获得株数）、飘字实现方式 motion→CSS
