# 灵植记 · 交互原型（game-proto）

阶段 1 界面交互原型：React 19 + Vite 7 + Tailwind CSS 4 + Zustand 5，与正式技术栈一致。
数据全部为内置 mock（小词表 + 预置局面），**不含存档、不含数值平衡**，仅用于确认视觉与交互。
经用户确认后，组件与交互迁移进正式工程；本目录按需迁移或删除。

对应设计文档：`doc/design/lingzhiji/ui.md`（原型选型决策记录于该文档「原型」小节）。
素材来源：`design/concept-art/`（复制于 `public/assets/`，勿在原型内修改原图）。

## 运行

```bash
# 本机 Git Bash 无全局 node，使用 nvm 安装目录（v22.14.0）
export PATH="/c/Soft/nvm/v22.14.0:$PATH"
npm install --registry=https://registry.npmmirror.com
npm run dev        # http://localhost:5173
npm run typecheck  # tsc --noEmit
```

## 覆盖范围

- 开始画面（山野场景 + 入宗引子 + 三种人物形象选择；所选形象同步到弟子侧栏与筑基结算）
- 主界面：顶栏（日期/境界修为/资源/功法）、灵田四态（空/生长/成熟/被收回）、行动面板（AP/任务堂/浇灌/灌注/吐纳/坊市/功法/应急领种/结束当天）、侧边弟子与日志
- 任务堂全流程：词库选择 → 先学后测 → 4 选 1 答题反馈 → 结果页（合格/不合格、错词入池）→ 领奖
- 坊市：购买（六种种子 + 残卷、九折、境界确认弹窗、灵石不足原因）、出售（行情系数）
- 月末定额：折算选择、自动预填、足额校验、首月免罚 / 欠缴罚则 / 连续欠缴收田
- 随机事件 toast（事件图标素材）、境界突破 toast、筑基结算成绩单
- 设置弹层（导出/导入演示桩）、新手引导 3 步、多标签横幅演示
- 调试面板（左下角）：跳月末、直达筑基、收田、词库异常态等，仅原型使用
