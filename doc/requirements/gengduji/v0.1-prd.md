## 1. 背景与定位

**为什么做**：原 english-town（英语学习 RPG）范围过大难以收敛，转向玩法更聚焦的产品。核心洞察有两条：

1. "自律行为 → 虚拟养成"的兑换循环已被 Forest 等产品验证；背单词相比"专注计时"的优势是**可验证**（测验判分，无法自欺）。
2. 把"种田"从休闲玩法升级为**生存压力驱动**的玩法（种田是为了活下去），解决单人农场 1–2 周新鲜感耗尽的留存问题。

**产品定位**：一款单机网页小游戏，玩家在逃荒生存的压力下背英语单词——背单词不是贴皮，而是游戏内"读书识字"系统，产出资源与长线增益。

**对标体验**：开局像《桃花村》式逃荒生存的紧张感，中段像QQ农场的种植节奏，背单词像 Forest 的"学习兑换"正反馈。

## 2. 核心循环

```
背单词(测验) ──合格──► 田地加速 + 学识 + 铜钱
     │                      │
     │                      ▼
     │              种田更高效 ──► 收获更多
     ▼                      │
  学识等级(长线)             ▼
  (生长永久加速/        喂饱全家 → 健康维持 → 活到结局
   收成加成/药膳)             │
                              ▼
                    撑过残冬 → 春耕 → 首茬收获 → 结局评级
```

- **短循环（每天，约 1–2 分钟）**：分配 3 点行动力 → 做饭喂饭 / 种田 / 赚钱 / 读书
- **中循环（每 10 天一旬）**：旬结算（家人送东西、房况老化）、货郎上门
- **长循环（90 天）**：残冬保命 → 春耕投入 → 收获变现 → 结局评级（S/A/B/C）

**设计铁律**：读书识字是唯一能同时产出"田地加速 + 学识等级"的行动，学习没有旁路替代。

## 3. 开局设定

- **故事**：荒年逃难，主控带着病重的母亲、年幼的弟弟（8 岁）和妹妹（6 岁）落脚山村"杏溪村"，租下一间漏风的破屋。父亲逃难途中失散（背景交代，MVP 无寻找剧情）。
- **初始家当**：铜钱 500 文、糙米 5 升、破屋一间（耐久 30/100，漏风）、无田地。
- **初始状态**：全家健康 60、饱腹 50；母亲健康 40（病重，开局自带"体弱"标记：每天额外 -1 健康，直到健康恢复 ≥70 解除）。
- **季节**：开局为腊月（残冬），大雪封村，无法种植。

## 4. 时间系统

| 项 | 规则 |
|---|---|
| 时间 tick | 1 回合 = 1 天 |
| 行动力（AP） | 每天固定 3 点，不结转；主控病倒当天仅 1 点 |
| 阶段 | 第 1–30 天 = 残冬（不可种植）；第 31 天立春 → 第 31–90 天 = 春耕期；第 91 天 = 结局结算 |
| 旬结算 | 每逢第 10/20/…/90 天触发（见 §9.2） |
| 天数推进 | 每天所有行动结束后点"结束这一天"→ 结算 → 次日 |
| 调试 | `?debug=1` 开调试面板：跳到任意天、加资源（仅验证用） |

## 5. 人物数值系统

### 5.1 属性

全家 4 人（主控/母/弟/妹）各有：

- **健康 0–100**：死亡判定依据
- **饱腹 0–100**：吃饭恢复

### 5.2 每日结算规则（顺序）

1. 饱腹：全家 -15（固定）
2. 健康变化（可叠加）：
   - 饱腹 ≤ 0 → 健康 -8/天
   - 残冬无柴火 → 全家 -3/天
   - 残冬且房屋耐久 <50 → 全家 -2/天
   - 母亲体弱标记（健康 <70 期间）→ 母 -1/天
   - 健康 <30 → 该成员额外 -2/天，且 30% 概率**病倒**（状态：每天额外 -3，服药立即解除，否则 3 天后自愈）
   - 自然恢复：饱腹 ≥40 且不受冻（有柴火或已立春）→ +1/天
3. 死亡判定：健康 ≤ 0 → 死亡 → **立即触发坏结局**

### 5.3 阈值与家人回报（保留参考游戏的暖点）

| 成员 | 健康达标 | 每旬回报 |
|---|---|---|
| 母亲 | ≥70 | 绣品 ×1（可卖 15 文） |
| 弟弟 | ≥60 | 山货 ×1（可卖 5 文） |
| 妹妹 | ≥60 | 山货 ×1（可卖 5 文） |

（未达标则当旬无回报 → 激励玩家喂饭照顾，而非只管自己）

## 6. 田地与种植

- **上限 5 块**，开局 0 块。开荒 1 块 = 2 AP（一次性完成）。
- 种子仅立春后（第 31 天起）可种植。

### 作物表（初版参数）

| 作物 | 种子价 | 生长期 | 产量 | 售价 | 用途 |
|---|---|---|---|---|---|
| 萝卜 | 8 文 | 20 天 | 4 个 | 3 文/个 | 做饭配菜 / 出售 |
| 白菜 | 10 文 | 25 天 | 4 棵 | 4 文/棵 | 做饭配菜 / 出售 |
| 药草 | 25 文 | 40 天 | 2 株 | 30 文/株 | 出售 / 自制药剂 |

- **浇水**：1 AP 浇全部已种地块；未浇记 1 个缺水日，累计缺水 ≥3 天 → 当茬产量减半。
- **收割**：成熟后 1 AP 收一块地。
- **读书加速**：当天读书合格 → 所有地块生长 +1 天（详见 §8）。

## 7. 行动清单（每天 3 AP）

| 行动 | AP | 效果 | 备注 |
|---|---|---|---|
| 做饭喂饭 | 1 | 全家饱腹恢复（见食谱表） | **每天必做**，否则死亡螺旋 |
| 下地浇水 | 1 | 全部地块免缺水 | 立春后才有意义 |
| 收割 | 1/块 | 获得作物 | |
| 开荒 | 2 | 新增 1 块田（上限 5） | |
| 上山 | 1 | 加权随机（见下） | 残冬主要收入 |
| 下河 | 1 | 鱼 40% / 空手 50% / 落水受伤 -10 健康 10% | |
| 读书识字 | 1 | 测验 + 奖励（§8） | 每天 1 次 |
| 照顾家人 | 1 | 指定一人健康 +6 | |
| 打短工 | 1 | 铜钱 +8~12（春耕期 10~15） | 稳定收入 |
| 修屋 | 1 | 木料 2 + 铜钱 20 → 耐久 +30（上限 100） | |
| 货郎商店 | 0 | 买卖（§10） | 每旬上门 |

**上山随机表**（残冬糊口的核心，方差大但有信息价值）：

| 结果 | 权重 |
|---|---|
| 柴火 ×2 | 30% |
| 柴火 ×1 + 野菜 ×1 | 20% |
| 野菜 ×2 | 15% |
| 药材 ×1（学识 Lv4 时 +1） | 15% |
| 木料 ×1 | 10% |
| 空手而归 | 8% |
| 受伤（健康 -15，当日行动终止） | 2% |

### 食谱表（做饭 1 AP，全家生效）

| 食谱 | 耗材 | 饱腹恢复 | 备注 |
|---|---|---|---|
| 稀粥 | 米 0.5 升 | +30 | 保命线 |
| 菜粥 | 米 0.5 升 + 菜 1 | +45 | 菜 = 萝卜/白菜/野菜 |
| 干饭 | 米 1 升 | +55 | |
| 鱼饭 | 米 1 升 + 鱼 1 | +65 | |
| 药膳 | 米 0.5 升 + 药剂 1 | +40，全家健康 +5 | 学识 Lv5 解锁 |

## 8. 读书识字系统（背单词，本作核心）

### 8.1 测验

- 进入需 1 AP，每天限 1 次
- **10 个英语单词，词→中文释义 4 选 1**（干扰项运行时从词库随机抽）
- 词库：内置 CET4 高频词约 300 个（JSON：word / 音标 / 释义），文件可整体替换（高考词、雅思词……）

### 8.2 奖励

| 结果 | 奖励 |
|---|---|
| 合格（≥6/10） | ① 所有田地生长 +1 天 ② 学识 +8 ③ 铜钱 +5（帮村人写信/记账） |
| 满分 10/10 | 合格奖励 + 额外学识 +4 |
| 不合格（<6） | 仅学识 +2 |

### 8.3 学识等级（长线背词动力，每级需 100 学识点）

| 等级 | 增益 |
|---|---|
| Lv2 | 所有作物生长永久 -1 天 |
| Lv3 | 收成 +15% |
| Lv4 | 上山采药 +1 株 |
| Lv5 | 解锁药膳；病倒自愈缩短为 2 天 |

### 8.4 学习统计

全程记录：累计背词数、正确率、读书次数 → 结局画面展示（学习成就感闭环）。

## 9. 随机事件与旬结算

### 9.1 随机事件

每天 35% 概率触发 1 个，按权重抽取（正面权重合计 ≈60%，负面 ≈40%——生存有压力但不劝退）：

| 事件 | 类型 | 效果 |
|---|---|---|
| 村长送旧棉衣 | 正 | 全家健康 +5 |
| 大婶送咸菜 | 正 | 菜（野菜）+2 |
| 好心邻居借米 | 正 | 米 +1 升 |
| 弟弟捡柴回来 | 正 | 柴火 +1 |
| 妹妹挖到野菜 | 正 | 野菜 +1 |
| 母亲精神好转 | 正 | 母健康 +8 |
| 邻村零活 | 正 | 铜钱 +10 |
| 货郎让利 | 正 | 当旬商店 9 折 |
| 山泉发现 | 正 | 柴火 +1 |
| 拾得旧木料 | 正 | 木料 +1 |
| 大雪压屋 | 负 | 房屋耐久 -3 |
| 夜雨漏屋 | 负 | 房屋耐久 -2 |
| 弟妹发烧 | 负 | 弟或妹健康 -12（服药立即解除） |
| 母亲咳血加重 | 负 | 母健康 -15（服药立即解除） |
| 野狗偷粮 | 负 | 米 -1 升 |
| 风寒流行 | 负 | 全家健康 -5 |
| 柴火受潮 | 负 | 柴火 -1 |
| 粮食霉变 | 负 | 米 -0.5 升 |

### 9.2 旬结算（每 10 天）

1. 房屋耐久自然 -1（年久失修）
2. 家人健康达标 → 发放回报物（§5.3）
3. 货郎次日上门（第 5 天到达，商店 0 AP 可用）

## 11. 结局判定

### 坏结局（任意时点触发）

任一家庭成员健康 ≤0 死亡 → 结局画面（交代谁没能熬过这个冬天 + 本局统计 + 重新开始）。

### 好结局评级（第 91 天，立春后首茬收获时）

| 评级 | 条件 |
|---|---|
| S | 全员存活且健康 ≥80，米 ≥15 升，铜钱 ≥200，学识 ≥Lv3 |
| A | 全员存活且健康 ≥60，米 ≥10 升，铜钱 ≥100 |
| B | 全员存活，米 ≥5 升 |
| C | 全员存活（勉强活下来） |

结局文案按评级分档（"熬过荒年，青苗满田"…），附本局统计：存活天数 / 累计收入 / 背单词数 / 正确率 / 学识等级。

## 13. UI 概述

- **单屏布局**：
  - 顶部状态栏：日期（腊月初三·第 3 天）、季节、铜钱、米、柴火、学识等级
  - 左侧：家人卡 ×4（姓名/健康条/饱腹条/病倒标记）
  - 中部：场景区（房屋耐久 + 5 块田地格子，显示作物与生长进度）
  - 底部：行动面板（剩余 AP + 行动按钮，不足置灰）+ 当日日志流
  - 弹层：货郎商店、读书测验（全屏）、事件提示（toast）、结局（全屏）
- **视觉方向**：暖纸底色 + 墨色文字 + 少量青绿/朱砂点缀的"田园手账"风；图标先用 emoji / 简单 SVG，不做重资产美术
- **开始画面**：故事引子两三句 + 开始新局 / 继续存档
- 实现阶段用 frontend-design 技能产出具体视觉稿

## 14. 技术方案

| 项 | 选型 |
|---|---|
| 构建 | Vite 7 + TypeScript strict |
| UI | React 19 + Tailwind CSS 4 |
| 状态 | Zustand 5（与 english-town 同生态，零学习成本） |
| 存档 | localStorage，每天行动结束自动存，带版本号；开始画面可继续 |
| 逻辑层 | `src/game/` 纯 TS（不 import React），UI 只读状态 + dispatch → 单测与模拟器直接复用 |
| 测试 | vitest：覆盖每日结算/死亡判定/旬结算/结局评级/测验判分 |
| 平衡模拟器 | `scripts/balance-sim.ts`：无头跑 500 局贪心生存策略，输出存活率/评级分布/死因直方图；调参目标：认真策略存活率 55–75%，乱玩 <20% |

```
src/
├─ game/            # 纯逻辑：types / constants / engine / events / quiz / save
├─ data/words/      # cet4.json 词库
├─ store/           # useGameStore (Zustand)
├─ components/      # TopBar / FamilyCard / FieldGrid / ActionPanel / DayLog / QuizModal / ShopPanel / EventToast / EndingScreen
└─ screens/         # StartScreen / GameScreen
```

## 15. 二期非目标（本版不做）

畜牧（鸡猪牛羊）、情缘/结婚/生育/孩子培养、科考与十年多结局、小镇地图（医馆/集市）、成就系统、音效、移动端深度适配、云存档/排行榜。

## 16. 验收标准

1. `npm run typecheck` 与 `npx vitest run` 全绿
2. 浏览器完整跑通一局：残冬生存 → 立春开荒 → 读书加速 → 首茬收获 → 结局评级；并验证一次坏结局路径
3. 存档：刷新页面后可从上次进度继续
4. 平衡模拟器：贪心策略存活率 55–75%，随机策略 <20%
5. 背单词闭环：测验合格后当帧可见田地进度 +1、学识条上涨
