## 试玩发现

### AI 实玩走查（2026-11-19，新档→第 3 月全程实测）

**P0 · 系统性矛盾（伤 T49 核心循环）**

1. **入定×浇灌互斥 → 推荐流程必减产**：实测第 2 月「入定至下次成熟」5 天，两块青灵草田全部缺水减半（预计 6+6 → 实收 3+3）。青灵草 5 天生长期内入定 ≥3 天必触发「连续缺水 3 天减产」，弹层只有一行静态警告，预演区不算「本次入定预计减产 X 田」。玩家按官方推荐快进 = 必亏一半产量，且无感知。
2. **灵气锚现实日 × 时间解耦 → 连玩 session 死局**：实测答错 2/10 → 灵气 +1 只够种 1 田；灵气耗尽后（3 空田、82 灵石）无事可做——灵石买不到灵气，只能吐纳/空转入定。第 1 月免罚无事，第 2 月欠缴实锤（灵石 −10、连续欠缴计 1），第 3 月继续欠缴将收田 → 连玩玩家死亡螺旋。sim 的 96% 达成率是 daily1（每日答题）口径，掩盖了连玩线。
3. **委托数量 vs 单田产量错位**：青灵草委托 7 株 > 单田预期产量 6（减产后 3）；实测卡「还缺 3 株」且灵气 0 无法补种，委托无限期挂起，缺口态无「去补」引导。

**P1 · 陷阱类（一次性伤害）**

4. **坊市「卖全部」无定额保护**：实测手滑清仓 → 月末无草可缴。建议默认保留定额所需或二次确认。
5. **空田浇灌不禁用**：实测播种前点浇灌白耗 1 行动力（按钮不判断有无生长中田）。

**P2 · 打磨类**

6. 入定「至月末」只是滑条端点标签非档位（1/3/7 有档），跨月要点 7 天 ×N 次。
7. 释义重复义项仍在（positive「确实的…；确定的」、vapour「n. 蒸汽；n. 汽，蒸气」）——T31 v2 清洗残留，影响题卡观感。
8. 委托奖励 rng 四选一可能出「凝露花种子 ×2」——对灵气短缺玩家无解（有种无灵气）。
9. 入定期仓库被动缩水（灵雀偷食 ×2）无任何提示，出关摘要只列事件名。

**亮点（保持）**：入定出关逐日摘要/日志折叠/明日预告、月末定额弹层文案（免罚说明/惩罚预告/自动预填）、播种弹层当令反季特质与禁用原因、委托跨月保留与缺口禁用、仓库折算口径三处一致。

**优化方向草案 → 已授权修复（2026-11-19 T54 交付，见 tasks/T54.md）**：#1/#2 由「闭关收益」一体化解决（灵泉阵护田免缺水 + 每满 3 天闭关纳灵 +1 灵气）；#4 卖全部保定额确认弹层；#5 空田浇灌禁用；#3 委托缺口态「播种约 X 块田可补足」引导。P2 打磨项（#6-#9）未动，待排期。
