# T25 · 现实日锚 M1 设计与实现

## 背景

产品全局复盘结论：游戏定位「背单词的长期习惯容器」，但游戏日可连推（模拟中位 71 天筑基）导致「一次性通关」，与现实日习惯错配（PRD §18 P0）。经三路开源调研（留存机制 / SRS+发音 / 音频+动画）后与用户确认体系化扩展方案，M1 为第一阶段。

## 拍板记录（2026-11-15）

- **软锚定**：保留连推自由；晨露奖励 + 地力透支（经营递减）+ 道心连胜引导现实日节奏；学习奖励永不递减。否掉的备选：硬翻转（游戏日=现实日，推翻现有循环且挡住勤奋学习者）、仅奖励层（不解决连推通关）
- **M1 先行**，M2-M4 依次推进（见下方方向）
- BGM 来源：Pixabay 挑选（M3 启动时给候选清单）；音效用 Kenney CC0
- **角色选择仅为外观，任何版本不加数值/玩法差异**（用户 2026-11-15 明确；已落 PRD §3 与 real-day.md 边界）
- **产品定位口径（2026-11-15，重要）**：种植灵植是游戏主体，背单词学习只是其中一条线路（回归用户最初构想「种田游戏，通过背单词等任务加速作物成熟」，见 memory）。PRD §1 已于同日按此修订（「种灵田、育灵植、供宗门、修自身」，原「背单词的长期习惯容器」废弃）；影响：① 种田玩法深化（种植决策质变：轮作 / 搭配增益 / 种植专精 / 更多灵植）应提为主线扩展方向并单独立项（阶段 0）；② M2 学习强化降级为「线路增强」，可缩水或后移；③ M3 氛围（含生长动画）对种田体验是核心，优先级上移
- 里程碑数值（灵石 30/80/200/888）、晨露（灵石 8/心得 5）、递减参数（事件率 0.15、修为 ×0.5）为初版值，balance-sim「每日 1/2/3 游戏日」策略验证后调
