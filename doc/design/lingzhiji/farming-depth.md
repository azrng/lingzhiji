# 种田深化第一批（特质 / 地力轮作 / 邻作 / 物候）

## 1. 需求追溯

- 覆盖 REQ §22（种田深化第一批，随本文档新增）：解决「种什么、种在哪、什么时候种」三个唯一解。
- 2026-11-17 用户痛点四选四（决策同质 / 内容量少 / 视觉单一 / 产出去向浅），授权直接实现并自加趣味点。
- 未覆盖（后续批次）：新灵植品种横向扩（M6b）、田间管理操作（M6b）、上品留种育种与 NPC 订单（M6c）、生长视觉阶段（素材到位另立项）、四内景（M5）。

## 2. 契约引用

- 存档 v2 → v3（save.md migrations 链）：`Field` 增 `fertility: 0|1|2`（默认 1）与 `lastCrop?: HerbId`；无接口契约变更。

## 3. 技术设计

### 3.1 灵植特质表（constants，数据驱动）

| 灵植 | 特质 | 规则 |
|---|---|---|
| 青灵草 | 固氮 | 真轮作进茬时收获后地力 +1；自身连作免罚（单作中性，轮作才有增益） |
| 凝露花 | 喜湿 | 自体免疫缺水：不累计 dry、不缺水减产 |
| 紫云芝 | 喜阴 | 播种时任一相邻田为高秆（赤髓参/龙血藤/九叶莲）→ 当茬产量 +1 |
| 赤髓参 | 驱虫 | 相邻田免疫「虫害」事件减产（事件照发，日志附注被护） |
| 龙血藤 | 深根 | 连作地力消耗减半（−1 → 0，向上取整） |
| 九叶莲 | 灵韵 | 超脱物候：不适季惩罚也不吃适季加成 |

实现为 `Herb` 上的可选字段（`nitrogen? / wet? / shade? / insectWard? / deepRoot? / allSeason?`），不加第二套特质系统。

### 3.2 地力与轮作

- 田块三档地力：0 贫瘠 / 1 常沃（默认）/ 2 肥沃。
- **播种时**结算产量修正并写入 `curYield`（事件增减、收获取整都在其上）：`curYield = base + 地力档修正 + 物候修正 + 邻作修正`，各修正见 §3.2–3.4；贫瘠 −1、肥沃 +1，修正后最低 1。
- **收获时**结算地力与茬口（sim 校准修正）：固氮 +1 **仅在真轮作进茬时**（上茬存在且 ≠ 本茬）——否则单作青灵草会永久锁死肥沃档、每茬白赚 +1 产量（实测 daily1 69→54.5 现实日，破 60-90 目标带）；连作 −1 对非固氮草生效（深根减半为 0）。净效果：青灵草单作中性（新手保底）、上茬换青灵草 +1（轮作奖励）、高阶草连作耗地。地力 clamp 0–2，随后 `lastCrop = 本茬`。
- 展示：田格「上茬：青灵草」+ 地力点（●●○）。

### 3.3 邻作搭配

- 相邻定义：按田 id 升序后紧邻（id 差 1 且都存在）——网格布局下的稳定口径。
- 喜阴（紫云芝）播种时快照结算；驱虫（赤髓参）在 `applyEvent` 的 yield 负事件选目标后判定：目标田相邻有生长中/成熟的赤髓参 → 产量不减，日志 text 附「赤髓参灵气所护」。
- 展示：加成生效的田格挂「相生」微光徽章（复用 fx-glow-gold）。

### 3.4 物候历

- 6 月循环映射三季（每季 2 月）：**生发季**（月 1–2）/ **长养季**（月 3–4）/ **收藏季**（月 5–6）；季节与月度灵潮并行展示（灵潮仍管事件权重，季节管种植）。
- 适播期：青灵草=生发、凝露花=长养、紫云芝=长养·收藏、赤髓参=收藏、龙血藤=收藏·生发、九叶莲=全季（灵韵）。
- 播种时：适季 +1、反季 −1（最低 1）、灵韵种不吃任何物候修正。
- 展示：播种弹层逐种标注「当令 +1 / 平季 / 反季 −1」；TopBar 日期区附季节名；月初灵潮日志带一句农谚（6 句池按季节取，风味兼教学）。

### 3.5 数值预算与平衡保护

- 修正源叠加上限：地力 ±1 + 物候 ±1 + 邻作 +1 = 单茬最多 +3（精心经营上限）；对 15 株定额与 69 现实日通关线的冲击由 sim 轮作策略对照验证，超限回调幅度。
- 新手保护：青灵草固氮连作净 0、初始三田默认常沃、物候反季仅 −1。

### 3.6 结算管线变更点

| 位置 | 变更 |
|---|---|
| `constants` | HERBS 增特质/适季字段；SEASONS 表；农谚池 |

## 4. 界面原型（增量）

```text
┌ 田 2 ────────────────── ●●○ 地力肥沃 ┐
│ 上茬：青灵草                        │
│   [紫云芝·成熟]（相生徽章：邻作赤髓参）│
└─────────────────────────────────────┘
播种弹层行：紫云芝  库存 2  喜阴·驱虫邻作加成  【长养季 · 当令 +1】
TopBar：第 3 月 · 第 12 天 · 长养季
```

| 状态 | 表现 |
|---|---|
| 默认 | 田格多两行信息（地力点 / 上茬），无其他变化 |
| 反季播种 | 播种日志标注「反季 −1」，弹层红字提示 |
| 被护事件 | 虫害日志 text 附「赤髓参灵气所护，产量无损」 |
| 旧档（v2） | 迁移后地力=常沃、无上茬记录，行为与现版一致 |

## 5. 交互与异常

- 播种修正全部**播种时快照**进 curYield：之后邻作变化/换季不回溯已种田（避免结算顺序歧义）；田格信息行展示当前持有的加成。
- 收获把田重置为 empty 时**保留** fertility / lastCrop（茬口与地力是田的属性，不是作物的）。
- 被收回的田：fertility / lastCrop 保留（赎回后延续）；confiscate → 赎回路径不重置。
- 连作判定只看上一茬（lastCrop），与间隔天数无关（KISS）。
- sim 新增轮作策略（同田轮换 vs 连作）对照；vitest 新增 farming-depth.test.ts（特质逐条 / 物候三态 / 地力三档 / 连作 / 迁移 / 校验）。
